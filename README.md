# Sanoj Kumar — Portfolio

Personal portfolio: **https://sanoj.codeorbitapp.com**

React 18 · Tailwind CSS 3 · react-icons (Create React App). Hosted on Cloudflare Pages.

All content (role, experience, projects, skills, education) lives in `src/data/profile.js`, taken
from the resume in `public/Sanoj_Kumar_Resume.pdf`. Update those two files when the resume changes.

```bash
npm install
npm start        # http://localhost:3000
npm run build    # production build in build/
```

Pushing to `main` deploys automatically.
