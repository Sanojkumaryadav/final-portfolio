# Sanoj Kumar — Portfolio

Personal portfolio: **https://sanoj.codeorbitapp.com**

React 18 · Tailwind CSS 3 · react-icons (Create React App). Hosted on Cloudflare Pages.

All content (role, experience, projects, skills, education) lives in `src/data/profile.js`.
The Resume buttons open a Google Drive file: upload a new version there (Manage versions) and the
link keeps working with no code change.

```bash
npm install
npm start        # http://localhost:3000
npm run build    # production build in build/
```

Pushing to `main` deploys automatically.
